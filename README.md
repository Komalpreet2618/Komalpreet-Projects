## 🚀 Projects

### 1. CivicPulse

**AI-Powered Smart City Issue Detection and Civic Issue Reporting Platform**

CivicPulse is a full-stack smart city platform designed to help citizens report and track civic infrastructure issues such as potholes, road damage, garbage dumping, broken streetlights, and water leakage.

The platform supports different user roles and provides workflows for reporting, managing, assigning, and tracking civic issues.

**Technology Stack:**

`React` · `JavaScript` · `Node.js` · `Express.js` · `PostgreSQL` · `PostGIS` · `Python` · `FastAPI` · `YOLO`

**Key Features:**

* User registration and authentication
* Role-based access for citizens, authorities, and administrators
* Civic issue reporting and management
* Issue status tracking and history
* Image-based issue reporting
* Geospatial location support using PostGIS
* REST API-based backend
* Planned AI-based civic issue detection
* Dashboard and analytics capabilities

**Project Status:** 🚧 In Development

🔗 **[View CivicPulse Repository](https://github.com/Komalpreet2618/CivicPulse)**
