# DASHGRADE

DASHGRADE is a Streamlit-based student performance and academic monitoring application.

## Features

* Student performance tracking
* MST1 and MST2 comparison
* Final marks visualization
* Attendance monitoring
* Student leaderboard
* Detain list based on attendance
* Medical attendance adjustment
* CSV upload and download
* Interactive dashboard

## Technology Stack

* Python
* Streamlit
* Pandas
* Plotly

## How to Run

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run dashgrade.py
```

The application allows users to upload student data through a CSV file and analyze academic performance through an interactive dashboard.
